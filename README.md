## Quiz App

A simple anime quiz app, the app allows users to answer 5 basic anime questions.

# Technologies Used

- HTML
- CSS
- JavaScript

# Installation

1. Clone this repository to your computer:

    ```bash
    git clone https://github.com/jfcaabaydev/Quiz-App
    ```

2. Open the project folder:

    ```bash
    cd Quiz-App
    ```

3. Launch the app by opening the index.html file in your preferred web browser.
